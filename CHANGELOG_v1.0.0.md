# Seu CRM foi atualizado — v1.0.0 🎉🎉

Conteúdo de referência da primeira release cadastrada no changelog do CRM.
Já foi inserido na tabela `releases` via `cadastro_release_v1.0.0.sql` — este
arquivo existe só como fonte legível pra copiar/editar se o texto do modal
precisar mudar depois.

## CRM

- **Notificações e mensagens** de qualquer sistema agora aparecem em um único
  menu fixo no topo, visível em qualquer tela.
- **Chat flutuante**: responda um chamado sem sair da tarefa que você está
  fazendo.
- **Dashboard reformulado**: mostra seus chamados, tarefas e prazos pessoais,
  com uma aba separada de visão geral para gestores.
- **Modal de atualizações**: sempre que o CRM ganhar uma novidade, um aviso
  como este vai aparecer no seu próximo login.

## Central de Suporte

- Nova coluna **"Parados"** no quadro de chamados, para tickets travados que
  não devem contar no prazo de atendimento.
- **Modo TV**: exiba os chamados em tela cheia num monitor, com som de aviso
  para chamados e mensagens novas.
- Notificação de mensagem separada da notificação de chamado, com contador de
  mensagens não lidas no card.

## Processamento de Ponto

- Sistema migrado para dentro do CRM — não abre mais em janela externa.

## Cálculo de Adiantamento

- Sistema migrado para dentro do CRM — não abre mais em janela externa.

## Aeronord

- Convocações e recibos migrados para dentro do CRM — não abre mais em janela
  externa.

## Cálculo de Comissão

- Novo sistema nativo do CRM para cálculo de horas extras 150%, com
  relatórios que agora salvam de verdade.
